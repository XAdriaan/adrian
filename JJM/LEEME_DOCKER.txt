JJM PROJECTSPHERE - PRODUCCION EN COOLIFY
======================================
Usar Docker Compose, con base directory /JJM y compose file /docker-compose.yml.
Asignar https://oficina.jjmti.com.mx solamente al servicio frontend (puerto 80).
El backend permanece interno en 8080; Nginx sirve HTML y proxifica /api/ a
http://backend:8080 conservando la ruta. No asignar el dominio a ambos servicios.

Conservar DB_URL, DB_USER, DB_PASSWORD, MAIL_USERNAME, MAIL_PASSWORD y JAVA_OPTS.
Este Compose no administra MySQL. No borrar bases, volumenes ni importar SQL.

Verificar tras desplegar main:
- / y /proyectos.html: 200 con HTML servido por Nginx.
- /api/salud: 200 con JSON de Spring Boot.
- /api/roles/mi-permisos con Bearer valido: 200 con rol, idRol, permisos y
  superadministrador. Sin sesion: 401.

El JAR conserva archivos estaticos de respaldo, pero la entrada publica debe
ser frontend Nginx en puerto 80.
