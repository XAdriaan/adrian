¿Qué es?

Una plataforma para organizar el ciclo completo de trabajo.

La Oficina de Proyectos permite registrar información operativa, dar seguimiento a tareas, controlar horas, administrar documentos, validar evidencias y generar reportes para la toma de decisiones.

📁

Administración de proyectos

Centraliza proyectos, fases, tareas, responsables, estados, prioridades y avances.

⏱

Control de horas

Registra jornadas, horas manuales, validaciones, historial personal y listas de asistencia.

📄

Expediente documental

Permite subir cartas de presentación, revisar documentos y liberar cartas finales.

Beneficios

Mayor control, trazabilidad y evidencia documental.

La plataforma ayuda a mantener una administración clara del trabajo realizado, reduciendo dispersión de información y facilitando el seguimiento por responsables.

Información lista para reportar

La información registrada se utiliza para generar reportes, validar horas, revisar documentos y mantener evidencia del avance de cada colaborador.

  • Datos académicos
  • Proyectos asignados
  • Horas trabajadas
  • Documentos validados
  • Reportes descargables
Flujo de acceso

Del registro al expediente operativo.

1

Crear cuenta

El usuario se registra con sus datos básicos de acceso.

2

Completar datos académicos

Se registra matrícula, universidad, carrera, cuatrimestre y periodo.

3

Usar la plataforma

El usuario accede a proyectos, tareas, horas, documentos y reportes.

4

Generar evidencia

Se descargan formatos y se gestiona el expediente final.

Acceso a la plataforma

Crear cuenta de colaborador

Después de registrarse, el sistema solicitará los datos académicos necesarios para cartas, reportes y expediente administrativo.

Importante: El registro inicial se crea con rol Colaborador. Los permisos administrativos solo pueden ser asignados por un administrador.
