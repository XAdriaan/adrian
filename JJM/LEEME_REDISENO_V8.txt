SUBIR A GITHUB
En PowerShell, abre la carpeta extraída del ZIP y ejecuta:

    .\SUBIR_V8.ps1

El script usa C:\Users\24050\Downloads\JJM_REPO_NUEVO, comprueba el repositorio
XAdriaan/adrian y la rama main, actualiza, copia JJM, crea un commit y hace push.
Si tu repositorio está en otra carpeta:

    .\SUBIR_V8.ps1 -Repositorio "C:\ruta\de\tu\repositorio"

Si PowerShell no permite ejecutar el archivo, puedes pegar estos comandos manuales.
Primero guarda con un commit los cambios locales pendientes, si los hay.
Ajusta $paqueteJJM si extrajiste el ZIP en otra carpeta:

    $paqueteJJM = "$env:USERPROFILE\Downloads\JJM_REDISENO_AZUL_VIDEOLLAMADAS_20261005_V8"
    $repoJJM = "$env:USERPROFILE\Downloads\JJM_REPO_NUEVO"
    if (!(Test-Path -LiteralPath "$paqueteJJM\JJM")) { throw "No se encontró JJM dentro del paquete." }
    if (!(Test-Path -LiteralPath "$repoJJM\.git")) { throw "El destino no es tu repositorio Git." }
    cd $repoJJM
    git status
    git pull --ff-only origin main
    if ($LASTEXITCODE -ne 0) { throw "No se pudo actualizar el repositorio." }
    robocopy "$paqueteJJM\JJM" "$repoJJM\JJM" /E /R:2 /W:1
    if ($LASTEXITCODE -ge 8) { throw "Falló la copia." }
    git add JJM
    git commit -m "Rediseña JJM en azul e integra salas generales y privadas"
    git push origin main

CONEXIÓN DE VIDEOLLAMADAS ENTRE REDES DISTINTAS
La nueva llamada usa WebRTC con señalización protegida por la sesión de JJM.
No pide otra cuenta de Jitsi ni comparte un enlace público externo para entrar.
Algunas redes móviles, empresariales o NAT restrictivas necesitan un servidor TURN.
Si la sala abre pero no conecta el video entre dos redes, configura estas tres
variables opcionales en el BACKEND de Coolify con los datos de tu servicio TURN:

    PMO_TURN_URLS        Una o varias URLs TURN/TURNS separadas por comas
    PMO_TURN_USERNAME    Usuario del servicio TURN
    PMO_TURN_CREDENTIAL  Credencial del servicio TURN

El compose ya pasa estas variables sin cambiar las variables existentes de MySQL.
No se incluyen credenciales inventadas ni un servidor TURN de terceros compartido.
La configuración de TURN se entrega solo a sesiones autenticadas.
Debe probarse la conectividad real después del despliegue; la prueba local no
demuestra que tu red móvil o corporativa permita conexiones directas.
